## YOLOX + NanoDet multi-detector baseline

The pipeline is **`implemented`**. The first production corpus was processed from scratch by YOLOX-Tiny run `29812888677` and NanoDet-Plus-m-320 run `29812888709`; publisher run `29813188073` paired their exact workflow run IDs under the complete corpus/hash contract and published ZIP-only [`media-detection-all-2026-07-13-v1`](https://github.com/PME26Elvis/media-experiment-ledger/releases/tag/media-detection-all-2026-07-13-v1).

- YOLOX produced 1,533 boxes; NanoDet produced 3,243; 902 same-class pairs matched at IoU ≥ 0.50.
- Mean disagreement was 0.5574. These are agreement/disagreement observations, not an accuracy benchmark.
- [Detector Lab](../web/src/content/docs/detector-lab.mdx) provides Original/YOLOX/NanoDet comparisons and versioned representative previews.
- [Production evidence](reports/NANODET_PRODUCTION_EVIDENCE.md) · [Complete contract](NANODET_MULTI_DETECTOR_PIPELINE_SPEC.md)
